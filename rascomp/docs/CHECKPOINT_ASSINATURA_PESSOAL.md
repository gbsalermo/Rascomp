# Checkpoint pessoal — Assinatura do projeto

**Status:** ⏳ opcional / não iniciado

Este checkpoint preserva a assinatura pessoal do backend, mas **não é uma etapa numerada do roadmap**.

O deploy é a ETAPA 16 e permanece a última etapa operacional. Se a assinatura for adotada, ela deve ser preparada no fechamento da **ETAPA 15 — Validação final completa** e seguir junto com os artefatos aprovados para produção.

Escopo possível:

- assinatura discreta no backend;
- marca/easter egg sem impacto funcional.

Restrições:

- não alterar regras competitivas;
- não alterar contratos de API;
- não alterar migrations;
- não enfraquecer segurança;
- não degradar desempenho;
- não criar dependência de execução.

A assinatura é acabamento autoral opcional e não requisito de conclusão do RasComp.
