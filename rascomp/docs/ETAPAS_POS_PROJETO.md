# RasComp — Etapas Pós-Projeto

O roteiro pós-aprovação é mantido como documento canônico no repositório de frontend, pois ele coordena backend, gestão, participante, Landing, mídia e uso institucional em um único plano.

Documento principal:

```text
gbsalermo/Rascomp-FRONT
docs/ETAPAS_POS_PROJETO.md
```

Este backend deve seguir especialmente as etapas relacionadas a:

```text
ETAPA 1  correções de lógica
ETAPA 2  limpeza técnica
ETAPA 3  nova matriz de permissões
ETAPA 4  Ajustes Gerais + auditoria
ETAPA 5  portabilidade institucional
ETAPA 6  Avisos + futuro Telegram
ETAPA 7  backend do CMS/mídia
ETAPA 8  regras públicas quando persistidas
ETAPA 9  Futebol de Robôs
ETAPA 12 hardening para uso externo
```

Ao concluir uma dessas etapas, atualizar também `rascomp/docs/CONTINUIDADE.md` e os testes automatizados correspondentes.

Ao final do ciclo existe uma bateria obrigatória de testes manuais com simulações reais, cadastros, permissões, operações competitivas, mídia, avisos e instalação por outra instituição.
